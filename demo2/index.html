Swarm Engine Integration

Learn how to reverse-engineer and mount an autonomous agent swarm onto any production webpage using zero external dependencies and Reynolds Boids physics.

⚡ Zero Build Tooling Required

Vortex mounts completely within an isolated Shadow DOM container. It never collides with Tailwind, Bootstrap, or custom CSS frameworks.

1. Installation

Add the universal package to your project dependencies using your preferred package manager:

bash — terminal Copy 
npm install dom-swarm
# or using pnpm
pnpm add dom-swarm

2. Basic Usage in Vanilla JavaScript

Mount the engine on DOM ready. All 18 agents will assemble into squads of 4 and begin building elements:

typescript — main.ts ESM 
import { enableSwarm } from 'dom-swarm';

const swarm = enableSwarm({
  agentCount: 18,
  teamSize: 4,
  concurrency: 4,
  hideOnStart: true,
  copyPasteDuplicates: true,
  vanishAtCursor: true,
});

3. Configuration Reference

Customize agent velocity, flocking distance, typewriter speed, and bounding wireframe geometries:

Property Type Default Description
agentCount number 18 Total number of autonomous cursor entities.
teamSize number 4 Squad size assigned to bounding box borders.
concurrency number 4 Simultaneous elements built in parallel.
vanishAtCursor boolean true Converge to user mouse and vanish upon completion.
