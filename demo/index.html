Two-Line Integration

Zero build configuration required. Drop it into React, Next.js, Vue, or straight into your HTML.

// 1. Install via npm, pnpm, or yarn
npm install dom-swarm

// 2. Enable in your entry point (Vanilla, React useEffect, or Next.js)
import { enableSwarm } from 'dom-swarm';

const swarm = enableSwarm({
  agentCount: 18,
  hideOnStart: true,      // Page starts blank, swarm builds it
  vanishAtCursor: true,   // Swarm converges & vanishes to cursor
  typewriterEffect: true,
  showGuides: true
});

Non-Destructive Shadow DOM Architecture

All SVG cursors, selection boxes, guide lines, and badges mount inside an isolated Open Shadow DOM. Host CSS rules never bleed into the swarm, and pointer-events remain completely unblocked.
