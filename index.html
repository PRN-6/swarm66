Core Engine Features

Engineered for Realistic Design Craft

Unlike ordinary CSS loaders, Swarm66 simulates real human designers collaborating live inside Figma.

SINGLE-AGENT CORNER DRAG

Figma Shape Drawing

Lead agents select the top-left anchor and drag diagonally across to dynamically size shapes and containers, with live pixel dimensions counting up in real-time.

DUPLICATE ⌥DRAG

Single Hand Cursor Glide

Identical cards and containers are detected automatically. Exactly 1 hand cursor grabs and slides a ghost wireframe duplicate across the screen.

TOOL MORPHING

Pen, Hand & Upright Pointers

Agents morph into vibrating pencil/pen tools for drafting headings, hand cursors for dragging, and naturally upright pointers without dizzying spins.

BOIDS PHYSICS

Reynolds Flocking Algorithm

Agents exhibit realistic swarm behaviors: separation to avoid collisions, alignment with neighbors, cohesion, and dynamic mouse orbiting at 60 FPS.

SPA ROUTING

Multi-Page Navigation

Intercepts pushState, replaceState, popstate, hashchange, Turbo, and Astro. Cursors wake up and construct new views dynamically when you change pages.

ZERO DEPENDENCIES

Ultra-Lightweight & Pure

Zero third-party runtime dependencies. Under 32 KB minified and gzip-ready. Mounts safely in an isolated, collision-free Shadow DOM overlay.

Lifecycle Pipeline

How Swarm66 Operates

From initial blank canvas to the grand finale convergence into the user cursor.

01

DOM Reverse-Engineering

Scans the host DOM, indexes hierarchy, and preserves original styles without touching your CSS.

02

Blank Canvas Start

The webpage starts blank with natural background colors, ready for the swarm to construct it.

03

Squad Border Locks

18 agents form 4-member teams to lock onto element borders, dragging wireframes and typing text.

04

Convergence Finale

All cursors accelerate into the user's mouse position, swirling into a ripple and vanishing cleanly.

Developer Integration

Works in Any Language or Framework

Universal compatibility with React, Next.js, Vue, Angular, Svelte, PHP, WordPress, Laravel, and plain HTML. 

// React / Next.js Component Integration (SSR Safe)
import { useEffect } from 'react';
import { enableSwarm } from '@leozodiac/swarm66';

export default function LandingPage() {
  useEffect(() => {
    const swarm = enableSwarm({
      agentCount: 18,
      teamSize: 4,
      hideOnStart: true,
      vanishAtCursor: true,
      typewriterEffect: true,
    });

    return () => swarm.destroy();
  }, []);

  return <main><h1>Autonomous Swarm UI</h1></main>;
}

FAQ

Frequently Asked Questions

Does Swarm66 hurt SEO or initial page indexing? +
No. Swarm66 operates strictly as a visual presentation overlay in the client's browser. Search engine crawlers (Googlebot, Bing) read your raw server-rendered HTML nodes without any alteration.
Does it work on smartphones and touch devices? +
Yes! Swarm66 automatically captures touchstart and touchmove events. Idle cursors smoothly orbit around your finger or thumb on mobile screens, and layouts adapt fluidly.
What happens when all elements are constructed? +
When all elements finish building, the grand finale triggers: all 18 cursors accelerate into the user's cursor position, swirling in an inward spiral, emitting micro ripples, and vanishing completely.
How does the single-agent corner dragging work? +
Instead of all agents expanding from the center, one agent selects the top-left anchor and drags the opposite bottom-right corner diagonally across to size the shape dynamically, just like a designer in Figma!
